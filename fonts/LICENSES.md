# Fonts

Both families are self-hosted from this directory so the site makes no third-party request.

- **Inter** by Rasmus Andersson - SIL Open Font License 1.1
- **Fraunces** by Undercase Type (Phaedra Charles, Flavia Zimbardi) - SIL Open Font License 1.1

Files here are the variable subsets published by Google Fonts, unmodified:

| file | family | subset |
| --- | --- | --- |
| `fraunces-var-latin.woff2` | Fraunces 300-900 | latin |
| `fraunces-var-latin-ext.woff2` | Fraunces 300-900 | latin-ext |
| `inter-var-latin.woff2` | Inter 400-600 | latin |
| `inter-var-latin-ext.woff2` | Inter 400-600 | latin-ext |
