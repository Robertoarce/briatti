# Working files

These are source and archive files that are not part of the published site. The leading
underscore keeps GitHub Pages' Jekyll build from copying this directory to the live site.

- `ba.html` — the standalone data-flow animation, kept for reference.
- `Briatti logo.fig`, `Briatti logo.svg`, `Briatti logo2.svg` — logo source files.
- `briatti.png`, `briatti_logo_unchanged.png`, `img/logo briatti.png` — logo exports.
- `img/qwenlogo.png` — the Briatti brand board: the five swatches, the icon tiles and the
  wordmark. The palette in `DESIGN.md` comes from this board.
- `img/data-flow.svg` — the earlier data-flow artwork.
